# Superstore Sales Analysis – SQL Assessment
**Celebal Technologies | Week 3**
**Name:** Ashmit Gupta


## About the Project
This project analyzes sales data from the Superstore dataset using SQL.
The goal was to practice Subqueries, CTEs, and Window Functions to answer
real business questions from the data.



## Dataset
- Source: Superstore Dataset (Kaggle)
- Link: https://www.kaggle.com/datasets/vivek468/superstore-dataset-final
- The dataset contains order-level sales data including customer info,
  product details, sales amount, discount, and profit.



## Tools Used
- Python (pandas, sqlite3, matplotlib)
- SQLite (for running SQL queries)
- Jupyter Notebook
